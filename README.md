# 01-titanic-eda
Titanic Survival Analysis- My first project

## Project Overview
Analyzed Titanic passenger data to identify survival patterns.

## Key Findings
- **38.4%** overall survival rate
- **74.2%** of women survived vs **18.9%** of men
- **63.0%** of 1st class survived vs **24.2%** of 3rd class
- Children under 10 had higher survival rates

## Files
- `titanic_analysis.ipynb` - Complete analysis notebook
- `titanic.csv` - Dataset
- `README.md` - Project documentation

## How to Run
